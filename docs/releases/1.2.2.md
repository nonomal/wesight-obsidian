# WeSight for Obsidian 1.2.2

发布日期：2026-10-11。

OpenLux 接入更名为词元API，默认 API 地址更新为 `https://ciyuan.today/v1`，继续使用原有 API Key。

## 更新

- 更新 Claude 供应商设置、聊天模型选择器、图标、错误提示和接入文档；词元API 排在 TokenDance 之后。
- 已保存的 OpenLux 配置和旧配置导入自动识别为词元API，旧默认地址自动更新。原供应商 ID、SecretStorage 密钥、完整模型 ID、自定义名称、目录能力及默认选择继续保留。
- 手动填写的其他请求地址继续使用原值。默认导出仍隐藏 API Key。
- 保留厂商分类、搜索、折叠和两栏模型选择器，以及 1.2.1 的 Claude 回复去重修复。

## 升级与验证

- 最低支持桌面版 Obsidian 1.11.4。手动更新使用本 Release 的 `main.js`、`manifest.json`、`styles.css`，更新后关闭再开启 WeSight 或重启 Obsidian。
- 已配置 OpenLux 的用户无需重新输入密钥；在 Claude 设置中确认词元API 地址及默认模型即可。自定义地址可按需要手动修改。
- `npm run check` 通过：496 项测试通过，1 项可选测试跳过；lint 无错误，类型检查、构建及发布资源校验通过。
- `wesight-obsidian-vault` 实机验证：供应商名称与新地址显示正确，原密钥、333 个模型及默认 `gemini-3.7-flash` 保留，连接测试通过；聊天选择器显示“词元API · Google”。
- 连接测试验证最小非流式消息；本次未另行实测完整 Claude Code 对话、流式工具调用和图片输入。

接入说明：[词元API](../ciyuan.md)。
